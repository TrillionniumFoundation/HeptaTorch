# Public F64 logical192 fixed reference

This package contains the exact original 192 dense public Float64 observations, two independent allocation observations, and six explicitly outside-native-scope Torch observations. The original producer, literal cases, public execution receipt, physical streams, staging record, six source/provenance inputs, actual Python executable identity and public lossless transfer chain are preserved. The Python file is evidence only and is not executed when restoring this package.

All 16 ordinary archive members are SHA256-, extent- and mode-bound by `manifest.json`. Original absolute paths inside the report and receipt are unchanged; `input_path_map` maps the six historical inputs to byte-identical local members. The original public receipt deliberately retains only the identity of its private service receipt.

This package contains observations, not a native PASS. The unchanged native reader compares 192 dense no-gradient cases and separately executes 18 packet controls, two real allocation rollback/retry controls, and two native scope controls. The last two reject public-F64 gradient creation and as_strided in the current native runtime; they are not counted as Torch compatibility. All six out-of-scope Torch observations remain visible. Original logical147 is a separate required suite covering other dtypes, private dtype3, views and gradients.
