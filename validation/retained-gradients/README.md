## Preserved contract-change failure

`reports/old-93-94-contract-failure.json` is the unchanged old reference-control
script's real first execution on the successor. It expected unknown-command
status 4 for command 93 with a valid requiring leaf. The new command succeeds
under its explicit contract, so the original script fails with observed 0
versus expected 4. That original report and its raw request/reply stream are
preserved.

`tests/retained_gradient_regression/custody.json` records three adapters and
their exact inverse transformations. The reference-control adapter changes
only the two now-valid command probes into nonzero-reserved-field refusals.
The private-lifetime adapter also changes the two private-format literals and
the corresponding diagnostic description. The gradient-clear adapter changes
only the two format literals. Every original source is recoverable byte for
byte. No numeric expectation, tolerance, object-lifetime assertion or rollback
comparison is weakened.

## Source custody and reproducibility

`authoring/` contains the actual host authoring and the native builder used in
the first construction route. It does not execute numerical operations.
`authoring/authoring-custody.json` records exact original-body re-emission,
the complete selected edits, declaration-only aliases with exact inverse
checks, and the four isolated private-tag changes. The emitted runtime has
410 unchanged parent functions, 18 replacements and 18 additions.

The standard producer is `tools/retained_gradients/build.py`: it reads the
frozen parent build and the checked HIA overlay, verifies function order and
hashes, and calls the fixed native compiler/linker. It needs no numerical
Python implementation or host compiler. The authoring route additionally
requires the pinned authoring module, its verified upstream source closure
and the pinned compactor; these inputs are recorded in the construction
receipt. The native compiler's limits and checks are unchanged.

The actual reference was produced by hosted run 43846646427, job 133228366300,
and is preserved at `reference/torch-retained-nonleaf.json` with SHA256
`ca8b5d3a7c679dcc5ad9a3d7b2bbd38f664c90e6474cf3e3c28496d5b716d1b3`.
The independent review package preserves the fixed probe and all eleven
provenance checks. No local Torch execution or simulated reference is claimed.

## Archives and remaining scope

The archives preserve complete candidate bytes, the two cold qualification
trees, and the early smoke/negative-control history. Every archive member was
verified against its source bytes, size and mode before freezing. Development
paths inside raw receipts are historical provenance; the archive members and
repository-relative report paths are the deliverable copies.

This first-order dense CPU binary32 profile does not implement sparse
gradients, create_graph, custom hooks, functional input capture or general
in-place graph rebasing. The low-level protocol still distinguishes atomic
backward from structured partial-error backward. The overall PyTorch rewrite
remains incomplete and retains denominator 2590.
