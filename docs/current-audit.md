The canonical application is **712 complete HIA core functions in 15 independently
compiled units**. It combines the existing Tensor runtime with native persistent
CPU Generator operations and a real four-argument entropy entry.

**The current nine-group/644-case production gate has passed on one actual 712
image. Its new source-head hosted admission remains PENDING.** Independent

complete stream EOFs and empty stderr. The new execution, completed cold build,
preserved earlier failures and separate pure-read admissions are recorded in

2,590 native declarations, 688 derivative declarations and 17 full-system gates.
Ten gates are IN_PROGRESS and seven are OPEN; zero whole gates and zero complete
upstream schemas are qualified. A finite test count is not a schema-coverage count.

## Cleanup and consumer boundaries

The current build consumes one canonical application source and no historical
application ELF. Needed original comparisons and custody witnesses remain fixed
fixtures; compiler bootstrap dependencies are a separate, necessary family.

The Generator migration removes nineteen obsolete live source files, the old
report checker and standalone package manifest. The original26 fixture retains
all nineteen source files, seven historical reports and the original manifest
with exact bytes and modes. The old checker is preserved in the source04 fixture.
The seven readable report paths and historical custody indexes remain in the
repository. [The retirement index](../validation/current-generator-original26/retirement.json)
maps every old file to its exact recovery location and keeps final qualification
conditional on the current gate.

Two old Generator workflow steps and their old Make targets are replaced by the
mandatory current131 group. The shared fixed Torch installation step, original
Torch oracle, RNG source used by other components, compiler bootstrap and all
unrelated qualifiers remain. The old live32 duplicate calls were already replaced
by its complete current group. Original76 uses the compact eight-file fixture;
the [complete historical archive location](../validation/view-reshape-r4-native76/archive-location.json)
remains recoverable after its Git copy was retired.

Remaining consumers still prevent blanket removal: 461 old protocol fixtures,
source-bound dtype/optimizer/resource tests, toolchain witnesses and the F64
oracle's exact old143-source binding. Removal requires a complete consumer map,
exact retained source/reference custody, unchanged comparison logic, actual
current-image qualification and source-head CI. Deleting a test or historical
failure is not a substitute for that sequence.
