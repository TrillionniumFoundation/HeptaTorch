## Custody graph

The fixed source-manifest binds configuration and every file of this source
package. Configuration pins four original native aggregate reports, four exact
input-custody records, original reference/probe bytes, the shared archive/manifest/
binding and the original operator receipt.

The shared 49e72 carrier is verified by the byte-identical original Sum archive
checker. Its explicit 315+22 role map is compared to real member metadata; no
member is accepted merely because its basename appears plausible. The actual
build report is read from its exact member, not reconstructed from a summary.
Its complete 177-input ledger and 14 source/object pairs are matched to original
archive entries, with all 15 original transports and complete stream bytes.

The new manifest inventories both original trees completely, including all raw,
owner and per-case files and directories. It also records the original source
package and 23 publication dependencies that were outside the shared carrier.
The original operator receipt is a full archive member. Every source is streamed
and rechecked, and the created archive is independently re-read with exact member
sets, lengths, modes, hashes, a single XZ stream and all-zero TAR EOF padding.
The manifest and evidence-binding remain outside the archive, with explicit
cross-hashes. A fresh output path is mandatory.

## Semantic replay

recorded_admission.py stages exact original input-copy bytes so protocol.py can
find its unchanged sibling owner_client.py. This changes location, not source.
The strict 0ead owner is read from the existing archive and bound through its
intended SOURCE/IMAGE API. No raw owner predicate is relaxed.

All four original native Case classes are loaded without calling their main or
constructing Native/Session. The frozen RecordedCase constructs packets with
the original event mapper and consumes a recorded session. Each original response,
snapshot, physical owner, identity relation and complete RNG state is corroborated.
The 32-scalar getter order is preserved. The 26-view epoch transformation remains
limited to the original proven released-object boundaries, never a blanket
ignore of identity mismatches.

Original checks performed against an unexported immediate before-owner are
identified as source-bound. Adjacent exported before/after owners are directly
rechecked when available. No global live transition claim or invented process
memory is introduced. Case-level errors are retained, do not shrink the fixed
76 denominator, and force the aggregate to fail.

## Expected limits

This package is a new SOURCE_ONLY artifact. Its future sealer proves custody;
its future recorded admission proves only exported-record consistency with the
frozen actual references. It does not rerun a native executable, recompute the
original oracle, regenerate the HIA source, or transfer old658 qualification to
the new image. The actual original696 native suite identity is bound separately.

The original same-image32 recorded admission is included byte-for-byte, together
with its reconstructed full native report. It is not invoked again. A complete
publication still needs an explicit portable path/mode mapping, source/build
regeneration and same-HEAD hosted CI. Zero full PyTorch schemas are closed.
