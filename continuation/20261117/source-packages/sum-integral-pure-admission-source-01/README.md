## Complete raw sealing

seal_raw.py reads the actual top report with its exact full SHA, byte length and
mode. It checks every embedded case and bounded-control report against its whole
original file. It inventories the entire original output directory, with no
filter or selected-case subset, and includes all original declared input files,
all root-supplied original execution evidence, this entire source package and
the exact seal plan.

Every archived file keeps its original mode and full bytes. Original directory
modes are retained; newly invented container directories alone are explicitly
0700. The uncompressed TAR is fully hashed, every member is checked, and exactly
one complete XZ stream plus the physical EOF is required. TAR padding after its
first EOF must contain only zero bytes. Links, sparse files, duplicate members,
undeclared members and silent path escapes are rejected.

Sealing is custody only. It preserves the actual producer status, including
FAIL or BLOCKED, and cannot produce a semantic admission. A successful seal
writes file-manifest.json, complete.tar.xz, report.json and evidence-binding.json
outside the original native directory. The original tree and every bound input
are checked again. The original report is never rewritten.
