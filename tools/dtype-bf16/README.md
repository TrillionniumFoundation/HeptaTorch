Native HIA BF16 bitwise conversion, isolated from the active storage/ABI work. mode=0 f32bits -> bf16bits (round-to-nearest ties-to-even); mode=1 bf16bits -> f32bits. Packet: u32 mode, u32 count, exact packed input. Output: u32 status (0 good, 1 rejected) plus packed result; reject counts over 200000. NaN is quieted on narrowing; tests compare NaN classification but not exact payload. A standalone component does NOT establish full PyTorch dtype/layout/schema qualification. Runtime has no Python, NumPy, PyTorch or host math dependency. Tests and compiler bootstrap are separate host/oracle dependencies.
