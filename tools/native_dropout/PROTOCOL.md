# Typed Storage, native_dropout and in-place detach profile

This profile extends the frozen retained-gradient parent (`666230f0…` / `7568c0a4…`) with real byte-wide bool Tensor objects and native CPU dropout. The complete generated HIA has 523 core functions in nine core units, plus the unchanged RNG and owned-state units. The compiler, linker, allocation backend and compilation limits are unchanged.

The inner wire remains `HTORCH03` / `HTORSP03` and the interactive envelope remains `HTOWNR01` / `HTOWNS01`. Internal state is `HTDTYP03`; the backing object state is `HTODTY03`. The descriptor is 640 bytes. A nonempty retained446 owner and a typed owner are mutually rejected with status 7. A trusted live-empty owner remains the initialization path. User packets never contain a native address or an owner capability.

## Typed data

| Dtype code | Meaning | Element bytes | Differentiable |
| --- | --- | --- | --- |
| 0 | CPU IEEE binary32 | 4 | Within the inherited supported AD operations |
| 1 | CPU bool | 1 | No |

Only these codes are admitted. Bool Storage contains one real byte per physical element. Generic Tensor address calculation scales element strides by the actual width. Constructor bytes for bool must be 0 or 1. Bool autograd requests are rejected before any F32 kernel can access the Storage. F64, I64, mixed-dtype promotion, casting and additional dtype kernels remain separate work; the metadata does not declare them implemented.

Shapes retain rank 0–4, per-dimension maximum 262144, zero-aware element-count checks, and the existing bounded arena/table limits. Command 97's payload is bounded by the 1 MiB request. Native dropout additionally limits nonempty work to 1,000,000 elements. A zero-element Tensor may have a nonstandard offset or stride under the inherited checked empty-view contract.

Commands are eight little-endian u64 words. Unused words must be zero. Payload offsets are absolute offsets in the inner packet, outside its command table. All ordinary refusals roll back the complete owned state, including Generator state and versions.

| Command | Fields after opcode | Result |
| --- | --- | --- |
| 96 | Tensor, query, 0,0,0,0,0 | Query 0 returns 32 bytes `[dtype, element_bytes, Tensor_incarnation, is_leaf]`. Query 1 publishes the actual Saved mask Tensor of a live native-dropout node. |
| 97 | dtype, configuration_offset, 0,0,0,0,0 | Creates a real typed Tensor. Configuration is eight words `[rank, requires_grad, d0,d1,d2,d3,data_offset,data_bytes]`. |
| 98 | Tensor, logical_start, count, 0,0,0,0 | Returns exactly `count * element_bytes` in logical Tensor order. No F32 reinterpretation is used for bool. |
| 99 | F32 input Tensor, Generator, probability_binary64_bits, training, 0,0,0 | Returns the output Tensor token and an eight-byte payload containing the actual mask Tensor token. Training is 0=False, 1=True, 2=None. |
| 100 | Tensor, raw_scalar_bits, no_grad, 0,0,0,0 | Width-aware fill, result 1. F32 uses a low-32-bit word; bool accepts 0 or 1. Exactly one Version increment, including empty tensors. |
| 101 | Tensor, 0,0,0,0,0,0 | Genuine `detach_`: returns the same Tensor, keeps Storage/Version/gradient and retained flag, clears current gradient history and requires-grad. Actual views are refused. |
| 102 | bool Tensor, 0,0,0,0,0,0 | Genuine bool `logical_not_`: logical byte zero becomes 1 and nonzero becomes 0. Returns the same Tensor and increments the shared Version once, including empty tensors. |

Command 13 retains its sixteen-word metadata. Its offset and Storage size are **bytes**, while shape strides are **elements**. Command 96 adds dtype and width without changing that established metadata meaning. Legacy F32 inspectors 10/11/39/40 and raw Hold/Saved F32 readers reject a bool target, including empty bool tensors. Command 98 is the typed data reader.

Wrong or stale typed handles remain status 1. Shape/range and incompatible gradient dtype/shape use status 2. Work/allocation/output-capacity exhaustion uses status 3. Unsupported gradient/view mutation uses status 5. Saved Version mismatch is 6; invalid flags, dtype, reserved words or unsupported bool numeric paths are 7; invariant violation is 9; spent Saved data is 10. Malformed packet or configuration byte ranges use 100. Admission ordering is tested: a cross-dtype gradient assignment can fail its existing shape/dtype check before the bool-target gradient restriction. No blanket remapping of errors is performed.

## Native dropout semantics

For nonempty input, output is F32 and mask is real bool. Output and mask allocation use their actual Preserve-layout rules. The mask is generated by the existing pinned CPU Generator implementation; the complete 5056-byte MT state, including normal caches, is preserved and compared in qualification.

`training=True` samples and applies the complement scale in both forward and backward. `training=None` takes the training forward branch but uses backward scale 1, matching the fixed upstream derivative and the actual reference. `training=False` creates a bool ones mask and clones the input, consumes no RNG, and does not apply the training probability-range check. Its observed NaN and out-of-range probability inputs are accepted. These distinctions are not implemented by collapsing None into True.

For empty input, the native function returns the **same Tensor and Storage**, with a separate empty F32 mask. Input and mask Preserve strides are retained; the mask is nondifferentiable. The empty branch consumes no RNG and bypasses the later probability check. A requiring leaf is not silently treated as a successful ordinary identity backward: the actual Tensor acquires NativeDropout history while its old captured AccumulateGrad still owns that Tensor. When that accumulator executes, the native runtime checks that the current Tensor has no gradient function and raises structured runtime error **11** if it was moved into the graph interior. An empty nonleaf whose old history leads to a different leaf can backpropagate successfully. A non-requiring empty forward followed by enabling the flag remains a different, valid case.

The native graph represents these relationships explicitly. It does not hardcode “empty backward fails.” Old child graphs, repeated native-dropout calls, retained hooks, default Saved release, flag changes and detach history all operate on the captured graph objects. Version mismatch and spent-Saved checks occur at their actual node before the captured accumulator can fail.

The actual pinned Torch behavior contains a strong cycle when an empty requiring leaf becomes its own history's captured accumulator target. Dropping all public locals or dropping a previously created Optimizer does not release that cycle. This profile preserves that observed behavior. Genuine `detach_` removes the current history edge and permits the cycle to be reclaimed; public detached aliases and unrelated old graph roots retain their own lifetimes. This is an explicitly qualified upstream corner case, not a claim that all user graphs or all native reference cycles are automatically collected.

## Real Saved-mask and gradient ownership

Native dropout saves the real public mask Tensor as well as its Storage and Version. Query 96/1 returns the same Tensor incarnation; it does not fabricate a new Tensor with matching values. Closing the mask's public token does not release its Saved ownership. Default backward releases visited Saved-mask ownership, while a surviving public mask remains usable. Mutating a Saved mask through fill or logical-not advances its true Version and causes the subsequent version check to reject it. Public Saved pack/unpack, clone, detach and views preserve dtype and byte width.

The inherited real public gradient object remains F32. Gradient assignment compares dtype as well as shape. Bool masks cannot enter incoming-gradient materialization, Optimizer numeric kernels, RNG F32 fills or legacy raw F32 paths through an unchecked four-byte access. The bool admission matrix includes a real write and RNG prefix followed by refusal, then compares the entire committed owner and full Generator bytes.

Commands 93/94 retain their actual retained-gradient semantics. A retained hook is attached to captured history and uses a weak real-Tensor target; it does not keep a dead Tensor alive by itself. The original first clone / later out-of-place replacement, prehook-before-runtime-error behavior and public held gradient aliases remain unchanged and are requalified against the original twelve variants.

## Optimizer membership after history changes

Creation and add-group commands still enforce the inherited leaf-or-retained parameter admission. Once a real F32 Tensor is already a private member, changing that same Tensor's current history does not retroactively invalidate membership. SGD and Adam-family member audits continue checking Tensor incarnation, dtype, shape, state-key relationships and exact private-reference counts; they no longer substitute the constructor predicate for the object's continued validity. Optimizer zero-grad accesses its already-owned real gradient without rerunning constructor admission. Public commands 8/70 retain their separate admission contract.

Fresh SGD momentum is cloned from the effective gradient. `maximize=True` first has the unary pointwise output layout; nonzero weight decay then has the actual gradient-plus-parameter pointwise layout. The unchanged numeric kernel writes through the resulting real Tensor strides. Plain no-maximize/no-decay cloning is unchanged. The first momentum Version is 0 and later updates advance twice. The implementation uses the frozen TensorIterator layout rules, not a special empty-shape stride table. Separate actual observations cover empty and nonempty transposed assigned gradients, all three branches, and two real steps.

## Descriptor and audit fields

All inherited fields at offsets 0–575 keep their roles. In particular Optimizer private Tensor roots at 312, monotonic Tensor incarnation at 320, captured old leaf references at 88, real gradient binding at 384/392/400, actual-view flag at 408, and incoming transient state through 568 are not repurposed. The original `[448,576)` transient-clear audit is intentionally not extended across the dtype field.

| Offset | Role |
| --- | --- |
| 576 | Dtype code |
| 584 / 592 | Saved actual mask node / its Tensor incarnation |
| 600 | Count of real-Tensor roots from Saved masks and captured accumulators |
| 608 / 624 | Tagged captured-history role or weak accumulator cache / corresponding incarnation |
| 616 | Temporary audit recomputation of offset 600; zero on every committed state |
| 632 | Captured AD creation-order override; zero means the original incarnation order |

The low sixteen bits of the tagged role identify an internal node, never an accepted public handle. An AD-only node can hold a strong accumulator target or a weak retained-hook target. A real Tensor can cache its accumulator weakly. These roles have separate retain/release rules and are included in the graph audit. Descriptor page size is `256 * 640`; pages, Storage offsets and graph roots remain stable across owned backing migration. No pointer is serialized into the object tables to fake an owned buffer capability.

## Qualification boundary

The full rewrite flag remains false and the original API denominator remains 2590. This component does not implement general dtype promotion, all PyTorch dtypes, GPU kernels, all Python wrapper properties, serialization or arbitrary external tensor storage. Private Python warning objects and `_saved_scale` attributes are not packet fields. The original distribution replay files retain their historical OPEN rows; the eight native-dropout observations are qualified additively rather than rewriting those reports. Named numerical, reference, lifecycle, rejection, allocation and owner-entry suites overlap and are never summed as unique upstream API coverage.
